# Quanto

Application personnelle de recettes de cuisine et de pâtisserie, avec recalcul automatique
des quantités selon le nombre de personnes ou la taille du moule.

- Application web installable (PWA), fonctionne hors ligne.
- Les recettes restent uniquement sur les appareils de l'utilisateur.
- Synchronisation directe et chiffrée entre appareils (WebRTC).

## Développement

```bash
npm install
npm run dev      # http://localhost:5173/quanto/
npm run build    # version de production dans dist/
```

La publication sur GitHub Pages est automatique à chaque envoi sur la branche `main`.
